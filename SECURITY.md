# Security Policy

## Response Process

After receiving a report:

1. We will acknowledge the report as soon as possible.
2. We will investigate and validate the issue.
3. If confirmed, we will prepare a fix.
4. A security advisory may be published after the fix is available.

## Supported Versions

Currently supported:

| Version | Supported |
|---|---|
| 0.1.x | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in GitIntel, please do not open a public GitHub issue.

Instead, report it privately by contacting:

- Gmail: contact@tahaboussaden.me
- GitHub: https://github.com/ThePhoenix77

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes
